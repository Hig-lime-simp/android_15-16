# Student Planner

## Описание приложения

**Student Planner** — это многоэкранное Android-приложение для управления учебным процессом студента, разработанное с использованием Jetpack Compose и Navigation Compose. Приложение позволяет просматривать список дисциплин с текущими оценками, изучать подробную информацию о каждом предмете, а также управлять личным профилем и настройками.

## Реализованные экраны

1. **HomeScreen** — главный экран со списком всех дисциплин
2. **DetailsScreen** — детальная информация о выбранной дисциплине
3. **ProfileScreen** — профиль студента с личной информацией
4. **SettingsScreen** — настройки приложения (уведомления, тема)

## Используемые технологии

- **Kotlin** — язык программирования
- **Jetpack Compose** — современный UI-тулкит для создания нативных Android-приложений
- **Navigation Compose** — библиотека для навигации между экранами
- **Material Design 3** — дизайн-система от Google
- **Android Architecture Components** — компоненты архитектуры Android Jetpack

## Схема навигации

```
HomeScreen (Главный экран)
│
├─→ DetailsScreen/{subjectId} (Детали дисциплины)
│       └─→ Back (возврат на Home)
│
├─→ ProfileScreen (Профиль студента)
│       └─→ Back (возврат на Home)
│
└─→ SettingsScreen (Настройки)
└─→ Back (возврат на Home)
```

**Типы навигации:**

- **Простая навигация** (без параметров): Home → Profile, Home → Settings
- **Навигация с параметрами**: Home → Details (передаётся subjectId)
- **Навигация назад**: popBackStack() для всех экранов

## Функциональность приложения

### Главный экран (HomeScreen)
- Отображение списка дисциплин в виде карточек
- Показ названия, преподавателя, баллов и текущей оценки
- Переход к деталям дисциплины по клику на карточку
- Кнопки быстрого доступа к профилю и настройкам в TopAppBar
- Использование LazyColumn для эффективной прокрутки

### Экран деталей дисциплины (DetailsScreen)
- Подробное описание курса
- Информация о преподавателе
- Текущая оценка и количество баллов
- Кнопка возврата на главный экран
- Получение параметра subjectId через навигацию

### Профиль студента (ProfileScreen)
- Личная информация (ФИО, группа)
- Информация об учебном заведении
- Email и курс обучения
- Статистика успеваемости (средний балл, количество дисциплин)

### Настройки (SettingsScreen)
- Управление push-уведомлениями (Switch)
- Выбор тёмной темы (Switch)
- Дополнительная информация о приложении
- Разделы "Справка" и "Выход"

## Ключевые архитектурные решения

### 1. Sealed Class для маршрутов
Использование `sealed class Screen` обеспечивает type-safety и централизованное управление всеми маршрутами приложения.

### 2. Разделение на пакеты
- **data** — модели данных
- **navigation** — логика навигации
- **ui_model** — UI компоненты (Composable-функции)

### 3. Callback-паттерн
Экраны не знают о навигации — они лишь вызывают переданные callback-функции. Это делает компоненты переиспользуемыми и тестируемыми.
